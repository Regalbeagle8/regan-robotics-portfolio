# Regan I. Owen Robotics Portfolio

This is a deployable React + Vite + Tailwind website.

## Deploy to Vercel

1. Unzip this folder.
2. Go to https://vercel.com
3. Click Add New → Project.
4. Upload or import this project folder.
5. Use these settings if asked:
   - Framework: Vite
   - Build command: npm run build
   - Output directory: dist
6. Deploy.

The robotics images are already included in:
public/images/robotics/

The resume button links to the provided Google Drive resume URL.
